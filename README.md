# AWS re/Start — Batch 33

Supplementary hands-on labs for AWS re/Start Batch 33 students. Use these walkthroughs to practice cloud concepts, explore AWS services, and check your understanding as you go.

This is a working repository. New labs and updates will be added as the class progresses. Check the lab index below for the available activities and follow each lab's README for its specific requirements.

## Available Labs

| Lab | What you will practice | Tools |
|---|---|---|
| [Amazon S3 Hands-On Walkthrough](s3-lab/README.md) | Bucket naming, uploading objects, versioning, encryption, access control, presigned URLs, lifecycle rules, and cleanup | AWS Management Console |

## Getting Started

1. Open a lab from the table above.
2. Read its prerequisites and confirm the required AWS Region before creating resources.
3. Follow the walkthrough in order and complete the checkpoints.
4. Complete any exercises or review questions included in the lab.
5. Follow the lab's cleanup instructions before ending your session.

You can read every walkthrough directly on GitHub. To keep a local copy:

```bash
git clone https://github.com/jjrs07/restart-batch33.git
cd restart-batch33
```

If you already cloned the repository, run `git pull` from its folder before starting a new lab to get the latest updates.

## Before You Start

- Have access to the AWS account or training environment assigned for your class.
- Follow your instructor's guidance on which resources you may create.
- Check each lab for its required tools, permissions, and AWS Region.
- Replace sample initials, bucket names, and dates with your own values where instructed.
- Delete resources when you finish to avoid ongoing charges.

## Adding New Labs

Each lab lives in its own folder with a `README.md` containing its instructions and any supporting files alongside it.

When adding a lab:

1. Create a folder with a descriptive name, such as `<topic>-lab`.
2. Add a `README.md` with the objectives, prerequisites, walkthrough, and cleanup steps where applicable.
3. Add a row to the **Available Labs** table above, linking to the new walkthrough.

Keep lab-specific setup details in the lab's README so this page remains a general entry point for the collection.

## Questions or Corrections

If a step is unclear or you spot an error, [open an issue](https://github.com/jjrs07/restart-batch33/issues) with the lab name, step number, and what happened. Keep passwords, access keys, and other credentials out of screenshots and reports.
